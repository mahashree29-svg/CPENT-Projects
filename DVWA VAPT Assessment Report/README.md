# DVWA VAPT Assessment Report

## Overview

This repository contains a Vulnerability Assessment and Penetration Testing (VAPT) report conducted on Damn Vulnerable Web Application (DVWA) as part of a cybersecurity training project. The assessment focuses on identifying, validating, and documenting common web application vulnerabilities along with their potential impact and remediation recommendations.

## Objectives

* Perform a structured web application security assessment.
* Identify and validate vulnerabilities in DVWA.
* Assess risk levels using industry-standard methodologies.
* Provide remediation recommendations for each finding.
* Document the complete testing methodology and evidence.

## Vulnerabilities Assessed

* SQL Injection (SQLi)
* Cross-Site Scripting (XSS)
* Command Injection
* File Inclusion
* Cross-Site Request Forgery (CSRF)
* Brute Force Authentication
* File Upload Vulnerabilities
* Security Misconfigurations
